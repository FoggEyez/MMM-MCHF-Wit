# Validation

Run `npm ci` and `npm test` from this standalone repository. Contract checks verify registration, bundled scripts/styles, parseable JavaScript, default settings and portable example configuration. Additional module behavior tests cover selected parsing, freshness and failure paths. docs/screenshot.png is rendered from the actual module in an isolated browser preview; fixture readings are marked demo.

These checks do not prove a live provider response, real router/SSH integration, replacement SD boot or physical mirror installation. This public package has not yet been installed on a second independent mirror. Start with a disabled entry and verify it before replacing a legacy module.
