# Wit troubleshooting

- Phrases are generated locally. An empty custom-only list falls back to the bundled phrases.
- Set transitionStyle to fade or none and transitionMs to 200–2400. Reduced-motion preferences skip fades.
- Use panelWidth, textSize and maxCharacters to suit the region. Layout styling belongs in your own custom.css.

Use the README for settings, dependencies, privacy and sources. For a bug report, include your device, MagicMirror and Node versions, the observed behavior and a minimal configuration with secrets removed. Do not post private feeds, tokens, precise home coordinates or network snapshots.
