# Use this module with Mirror Mischief

[Mirror Mischief project hub](https://github.com/FoggEyez/Mirror-Mischief) · [All Mischief modules](https://github.com/FoggEyez/Mirror-Mischief#mirror-mischief)

Mirror Mischief is the companion developed alongside this module to make installation, configuration and layout easier. Its existing development interface supports module browsing, Install from a link, generated settings, layout placement, setup checks and configuration restore points.

**The public companion installer is not yet released.** You can install this module independently now using its README. This repository contains the module, not a copy of the full companion application.

If you already use the companion:

1. Open Browse modules → Install from a link and paste this repository URL.
2. Open Module settings and choose your preferences. Read the module guide for provider or platform requirements.
3. Pick a mirror region, save, then run Check setup and inspect your display.
4. Keep to one instance per module in this release. Disable a legacy counterpart before enabling its new Mischief version.

The module exposes literal defaults for automatic settings discovery. companion.json documents placement, settings and dependencies; the current companion does not automatically import that file. The module needs no companion account, analytics or cloud service. Module-specific public data providers are documented separately.

Follow the hub for companion release availability and the collection roadmap. Report module bugs in this repository and companion questions in the hub.
